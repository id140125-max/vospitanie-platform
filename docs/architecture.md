# Архитектура

Frontend и backend разделены и взаимодействуют через REST API. PostgreSQL хранит структурированные данные, а файлы отчётов будут вынесены в S3-совместимое хранилище.

ИИ-ассистент должен работать через отдельный серверный модуль. Он может искать данные через разрешённые операции API, но не должен самостоятельно менять статусы заданий, отправлять отчёты или сообщения без явного подтверждения пользователя.
